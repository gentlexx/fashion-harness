# Roadmap and Capability Boundaries

English | [中文](roadmap-and-boundaries.zh.md)

## 1. Long-term loop

The long-term direction is:

```text
Compliant fashion and trend information
→ cleaning, standardization, and multimodal understanding
→ Fashion Dataset / Fashion Ontology
→ trend analysis and design opportunities
→ Harness-assisted research and design decisions
→ designer review, professional-tool refinement, and delivery
→ designer feedback, evaluation, and available market outcomes
→ the next model, rule, and workflow improvement cycle
```

The long-term assets are the combination of Dataset, Ontology, Harness, designer feedback, and evaluation system—not one model.

## 2. Current implementation boundary

The current repository implements only one verifiable slice of that loop:

```text
Brief
→ small traceable research set
→ trends and design opportunities
→ three design directions
→ human review and version change
→ delivery snapshot
→ feedback and evaluation records
```

This slice tests product structure, domain rules, Agent context, and delivery evidence; it is not a complete commercial product.

## 4. Claims not made today

- no live global-fashion collection;
- no sales prediction or proven commercial effect;
- no complete Fashion Dataset or Ontology;
- no trained or fine-tuned vertical fashion model;
- no image, video, CAD, or Tech Pack production line;
- no completed real-designer user study;
- no autonomous multi-agent production system with write access;
- no claim that every line was independently handwritten by the owner.

## 5. Near-term priorities

1. complete T-06 candidate validation and repair real blockers;
2. capture screenshots and runtime evidence only from the final application commit;
3. establish a repeatable designer-study script and feedback template;
4. prioritize reference integrity, Brief revision, and evaluation portability;
5. discuss controlled write tools and multi-agent collaboration only after those foundations;
6. map each issue back to the personal learning plan and next acceptance criteria.

The roadmap changes with evidence; a planned capability is not an implemented one.
