# Fictional Walkthrough：Transitional Utility Jacket

[English](README.md) | 中文

这是一个**完全虚构、不可导入、非客户案例**的叙事样本，用来帮助读者理解 Fashion Harness 的对象如何从 Brief 连接到研究、分析、三个设计方向、人工审核、交付和评估。

它不证明真实市场趋势、设计师满意度、销量、商业效果或最终浏览器流程已经通过。示例中的 URL 使用保留域名 `example.com`，所有人名、项目、反馈和数值均为演示用途。

## 场景

一个虚构团队希望为 2026 年秋季美国市场探索女装轻量通勤夹克。Brief 强调可层搭、柔和实用风格和三个明显不同的方向。

叙事过程：

1. 建立 `ResearchTask`，登记两个虚构 `Source`；
2. 从虚构 `Sample` 形成待人工复核的 `Evidence`；
3. 运行一次 `AnalysisRun`，得到一个 `TrendCluster` 和一个 `DesignOpportunity`；
4. 选择机会的精确版本，创建恰好三个 `DesignConcept`；
5. 虚构审核者要求修改第二个方向；
6. 修改使旧审核不再代表最新内容，重新审核后才可形成 `DesignDeliverable`；
7. `OutcomeAvailability` 标记为 `not_yet_observed`，不填写销量或市场结果；
8. Evaluation 记录规则结果与待改进事项，不自动修改业务对象。

## 三个方向

- **Cropped Transit**：短版、结构化、强调城市通勤；
- **Soft Field Layer**：较柔软、可层搭、强调日常适配；
- **Modular Longline**：长版、模块化细节、强调天气变化。
