# Contributing

English | [中文](CONTRIBUTING.zh.md)

Fashion Harness is currently maintained as a portfolio and learning project. The first public release prioritizes reproducibility, reviewable evidence, and a clear boundary from the upstream DeepSeek Harness project.

Before a public issue or pull-request workflow is enabled, please use this repository as a read-only reference. Do not send credentials, private design files, client information, copyrighted product images, or unpublished interview material.

Issues in unchanged upstream behavior should be reproduced against the upstream project before being attributed to Fashion Harness. Fashion-specific reports should identify the affected `@gentlexx/*` package, the application revision, the expected behavior, and a minimal reproduction without private data.

Feature proposals are evaluated against the current product boundary: traceability, human authority, project isolation, revision correctness, data rights, and reproducible evaluation. A larger agent count or a new model provider is not accepted as value by itself.
